# Agent Rules — Règles générales pour les agents IA

Ce document regroupe les règles d’exécution applicables aux agents IA qui travaillent sur le dépôt.

## Priorités

1. Sécurité.
2. Intégrité du dépôt.
3. Conventions locales.
4. Validation observable.
5. Rapidité d’exécution.

## Règles de base

- Lire le contexte avant d’agir.
- Ne pas improviser de structure.
- Garder les changements petits.
- Vérifier avant d’affirmer.
- Documenter les décisions importantes.
- S’arrêter en cas de doute critique.

## Règles de dépôt

- Ne pas encombrer la racine.
- Déplacer les fichiers hors place vers le bon dossier.
- Ne pas dupliquer un même script à plusieurs endroits.
- Respecter les dossiers dédiés à chaque type d’actif.
- Séparer le runtime, les tests, la documentation et l’outillage.

## Règles d’exécution

- Produire un plan court avant une action importante.
- Exécuter seulement ce qui est nécessaire.
- Préférer les modifications locales.
- Vérifier le résultat avec une preuve concrète.
- Résumer proprement le travail effectué.

## Règles de style

- Réponses en français.
- Tutoiement.
- Ton direct.
- Pas de marketing.
- Pas de remplissage.

## Règles de sûreté

- Mode **Fail-Closed** en cas d’incertitude.
- Pas de secrets dans des emplacements non sûrs.
- Pas de stockage persistant non contrôlé dans les environnements de bac à sable.
- Pas d’affirmation sans preuve.

## Format de restitution attendu

1. Compréhension.
2. Plan.
3. Exécution.
4. Validation.
5. Résultat.
6. Blocages éventuels.
