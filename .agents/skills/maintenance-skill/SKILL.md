# Skill — Maintenance

## Objectif

Centraliser les scripts, procédures et bonnes pratiques pour la maintenance préventive et corrective du site MonCoachScolaire.

## Fonctions principales

- Scripts de maintenance régulière (backup, nettoyage, optimisation)
- Procédures de mise à jour (dépendances, migrations, sécurité)
- Suivi des tâches de maintenance planifiées
- Documentation des interventions dans `references/`

## Checklist obligatoire

- Sauvegarde avant toute opération destructive
- Journaliser chaque intervention (date, auteur, action)
- Tester les scripts sur un environnement de test avant production

## Bonnes pratiques

- Utiliser les scripts versionnés dans `scripts/`
- Documenter chaque procédure dans `references/`
- Planifier les maintenances hors horaires d’affluence
