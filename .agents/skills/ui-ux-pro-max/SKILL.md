# Skill — UI/UX Pro Max

## Objectif

Fournir des ressources, guidelines et scripts avancés pour concevoir des interfaces et expériences utilisateur de niveau professionnel, adaptées à MonCoachScolaire.

## Fonctions principales

- Accès à des bases de données UI/UX (charts, couleurs, icônes, landing, produits, styles, typographie, reasoning, guidelines, web-interface)
- Scripts d’aide à la conception (génération de design system, recherche, audit performance UI)
- Référentiels de stacks front modernes (Astro, React, Vue, Svelte, etc.)
- Guidelines pour l’accessibilité, la cohérence visuelle, la performance et l’expérience utilisateur

## Checklist obligatoire

- Respecter les standards d’accessibilité (WCAG 2.1 AA)
- Utiliser les guidelines de la data/ux-guidelines.csv et data/ui-reasoning.csv
- Tester la cohérence et la performance UI avec les scripts fournis
- Documenter toute adaptation ou extension dans le dossier data/

## Bonnes pratiques

- S’inspirer des stacks référencées pour chaque nouveau composant
- Utiliser les scripts pour générer ou auditer un design system
- Centraliser les retours utilisateurs et itérations dans data/
