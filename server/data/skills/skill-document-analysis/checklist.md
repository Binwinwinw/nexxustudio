# Checklist : Document Analysis

- [ ] Le briefing ou le bloc `DOCUMENTS DE CONTEXTE FOURNIS` est-il présent ?
- [ ] La réponse cite-t-elle au moins un élément **observable** du fichier ?
- [ ] La structure Markdown est-elle conforme (analyse, points clés, risques, recommandations) ?
- [ ] Aucune phrase « Je n'ai pas assez d'éléments fiables… » si document joint ?
- [ ] Le streaming est-il actif (tokens progressifs, pas un bloc unique) ?
- [ ] Les limites (troncature, PDF) sont-elles mentionnées si applicables ?
