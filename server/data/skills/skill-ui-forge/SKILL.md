# Skill : UI Forge (v1.0 - SOTA Taste)

## 🎯 Mission
Éliminer le "AI Slop" et forger des interfaces premium, fluides et typographiquement excellentes.

## 🚫 Anti-Patterns (Interdictions)
- **Typo** : Pas de browser-default (Inter partout). Utiliser des échelles de type contrastées.
- **Couleurs** : Pas de dégradés "AI" génériques (violet/bleu saturé). Utiliser des palettes harmonieuses (ex: eduBlue/eduGreen).
- **Cards** : Pas de cards imbriquées à l'infini. Utiliser l'espacement et la hiérarchie visuelle.

## 🛠️ Commandes de Polissage
- **/audit** : Analyse la cohérence, l'espacement et l'accessibilité.
- **/polish** : Ajoute des micro-animations Framer Motion et affine les arrondis (border-radius).
- **/normalize** : Aligne les composants sur le design system de MonCoachScolaire.

## ✨ Principes de Design
1. **Glassmorphism** : Utiliser avec parcimonie pour la profondeur.
2. **Micro-interactions** : Chaque clic doit avoir un feedback (hover, scale, transition).
3. **Hiérarchie** : L'information la plus importante doit être lisible en < 1 seconde.

## 🛡️ Règle d'Or
Si l'UI semble générique ou "sortante d'une IA", elle doit être /polished.
