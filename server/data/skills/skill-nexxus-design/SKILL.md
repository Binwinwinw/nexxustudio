# Skill : Nexxus Design (v1.0)

## Mission

Designer **stratégique et opérationnel** de La Citadelle : direction artistique, design system, architecture d'interface, composants, mood, UX copy, micro-interactions et guidelines de production.

## Quand l'utiliser

- « Conçois une interface »
- « Refonds cette page »
- « Donne-moi une DA »
- « Prépare un design system »
- « Forge une landing / cockpit / webapp »

## Sorties (contrat v1)

| Artefact | Description |
|----------|-------------|
| `blueprint` | Structure layout, zones, flux |
| `tokens` | Couleurs, typo, espacements, rayons |
| `components` | Specs composants réutilisables |
| `page_structure` | Hiérarchie des écrans |
| `ux_copy` | Ton, labels, micro-copy |
| `guidelines` | Règles de production Forge/UI |

## Non-objectifs

- **Ne pas auditer** sa propre qualité finale → `skill-impeccable`
- **Ne pas extraire** l'ADN d'un site externe → `skill-design-extract`
- Pas de génération d'assets raster/vidéo en v1

## Pipeline type

1. (Optionnel) Entrée ADN depuis Design Extract
2. Nexxus Design produit proposition structurée
3. Enchaînement recommandé → Impeccable avant merge Forge

## Intent

`DESIGN_CREATE` — max **1 skill design actif** par tour.
