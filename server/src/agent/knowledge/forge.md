# Fonctionnement de la Forge

La Forge prend le relais une fois le projet validé. Elle enchaîne une analyse, une structuration d'architecture, une phase de développement si nécessaire, puis un contrôle QA avant de produire un dossier projet et des fichiers de cadrage.

La Forge est le pipeline de production de Nexxus Citadel.

Elle prend le relais une fois le projet suffisamment cadré et validé par l'assistant.

## Étapes réelles

1. Analyse du handoff projet.
2. Structuration d'architecture.
3. Développement si le projet exige du code ou du scaffolding.
4. Contrôle QA et validation finale.

## Sorties attendues

- un dossier projet structuré
- des artefacts de cadrage et de conception
- des fichiers Markdown ou JSON permettant de finaliser le projet

## Limites

La Forge ne doit pas inventer une organisation humaine, une équipe fictive ou des rôles non définis dans la documentation produit.
