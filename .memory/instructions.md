# Project Instructions & Behavior

## Development Standard: Béton Armé
- **Bluntness**: Speak and document directly. 
- **No Jargon**: Use plain language unless technical precision is required.
- **Hemingway Style**: Short sentences. Maximum impact.

## Architecture Rules
- **Full-Stack Independence**: Always maintain the separation between the React frontend and the Node.js backend.
- **Physical Creation**: Every major feature implementation must be reflected in the local project structure.
- **Local AI First**: Prioritize local LLM integration (Ollama). Failover to cloud only if explicitly requested.

## Style Enforcement
- **Liquid Glass**: Never deviate from the deep space aesthetic.
- **Micro-Animations**: Every interactive component must have a visual feedback/animation.
- **Clean Code**: JS (ESM), React (Hooks only), CSS (Variables).
- **Zero-Patch Protocol**: Forbidden to apply local fixes to systemic failures. Trace the pipeline. Recalculate logic. Document the trace.

## Hybrid Intelligence Standard
- **Strategy & Ideation**: Use large parameter models (Gemma 4 26B+) in RAM for deep reasoning.
- **Implementation & Audit**: Use specialized smaller models (Qwen 2.5 Coder, DeepSeek-R1) in GPU for speed and precision.
- **Brainstorming First**: Always encourage the use of the Brainstorming mode before launching production.
