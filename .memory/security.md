# Security Protocols

## Data Sovereignty
- **Local Sovereignty**: All AI requests must stay within the local network (Ollama).
- **Physical Isolation**: Keep project generation inside the `projects/` directory.

## Standalone Access
- **CORS Management**: Only allow the local Vite dev server (port 5173) to access the backend.
- **CSRF Token**: Use `NEXXUS_WEB_BYPASS` only for trusted local dev sessions.

## File System Safety
- **Path Sanitization**: Ensure all file paths generated by experts are relative to the project root. 
- **Destruction Prevention**: Do not allow deleting directories outside the `projects/` scope.

## Web page fetch (WEB_SUMMARY) — 2026-07-25
- Outil : `server/src/utils/urlExtractor.js` (pas le SERP `expert_web_search`).
- **Obligatoire** avant chaque hop GET : `validateEgressUrl` (`ssrfProtection.js`) — bloque localhost, RFC1918, metadata cloud, DNS rebinding.
- Redirects manuels (`maxRedirects: 0`) : re-validation SSRF+DNS sur chaque Location + URL finale.
- UA honnête : `NexxusCitadel/1.0` (ADR-011) — pas de spoof navigateur.
- Timeout 8s, rate ≥2s/hôte (stamp après succès), plafond corps 2 Mo, texte 15k.
- Content-Type HTML/XHTML/plain seulement.
- `sanitizeToolOutput` à l'extract + double sanitize pipeline (`---BEGIN/END PAGE---`).
- Politique contenu : login/paywall/captcha → fail-closed.
- URL **fournie par l'utilisateur** ≠ crawl autonome : pas d'allowlist domaines, mais SSRF toujours on.
- ADR-011 reste **SERP-only** pour `expert_web_search` ; fetch page = chemin distinct (ADR complémentaire souhaité).
