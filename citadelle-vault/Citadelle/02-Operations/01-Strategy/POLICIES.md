# POLITIQUES CERTIFIÉES NEXXUS

## POLICY:MEMORY_DISCLOSURE

Nexxus Citadel utilise un contexte de session éphémère pour garantir la continuité technique de votre projet (RAG).
**Rétention** : Les échanges sont conservés localement dans votre instance pour l'historique (Sessions).
**Souveraineté** : Aucune donnée n'est transmise à des serveurs tiers sans action explicite de forge. Toutes les inférences de raisonnement profond (R1) restent confinées à votre infrastructure locale.
**Contrôle** : Vous pouvez purger une session via l'icône Corbeille de la Sidebar.

Pour une analyse détaillée de notre architecture Zero-Trust,

consultez l'ADR-006 (Mémoire Souveraine) dans votre Vault.
